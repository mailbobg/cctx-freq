This extends R11 source feasibility, not a return/strategy trial. Official Tardis documentation provides unauthenticated first-of-month files. Source specifications: https://docs.tardis.dev/downloadable-csv-files/api.md ; https://docs.tardis.dev/downloadable-csv-files/data-types.md . Quote columns use microsecond UTC exchange/arrival timestamps. Bid/ask price and size refer to actual top-of-book; absent sides remain absent. Original capture order breaks ties, and nonmonotonic exchange timestamps must not reorder information availability.
